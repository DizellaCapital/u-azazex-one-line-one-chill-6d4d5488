make.fun bounty entry: one line of horror — a single sentence under 200
characters that has to frighten a reader in one breath.

## The line

> At 3:04 a.m., the library's return slot clinked, and the book I checked out in 1998 slid back across the desk — stamped DUE TODAY, in my dead father's handwriting.

163 characters. A scene, not a quip: a 3:04 a.m. anchor, a concrete object (the
book checked out in 1998, the DUE TODAY stamp), and a final clause that
reframes the whole line — the stamp is in the handwriting of the narrator's
dead father. No mirror, no doll, no basement, no baby monitor.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is 1–200 characters, one line, one
complete sentence, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback
`/output`), then reads it back to verify the written bytes match.
